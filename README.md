# ClassicRunDex

Thai-first Player Guide for Cookie Run Classic progression decisions.

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run typecheck
npm test
npm run build
```

The first durable app path is intentionally small: open the app, see the Thai Player Guide answer first, then inspect nearby Player Data and Source Records. Historical Cookie Run Kakao and community material remain labelled as leads until reviewed against Cookie Run Classic.
