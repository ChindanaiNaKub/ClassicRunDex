# ClassicRunDex

ClassicRunDex is a player-facing knowledge site for Cookie Run Classic, informed by earlier Cookie Run Kakao data where that data is relevant and responsibly usable.

## Language

**Cookie Run Classic**:
The currently reopened classic Cookie Run game that ClassicRunDex is meant to help players understand.
_Avoid_: old game, reopened game

**Cookie Run Kakao**:
The Korean predecessor or related version used as a potential source of historical game data and player knowledge.
_Avoid_: Korean version, Kakao version

**Player Data**:
Sourced, verifiable game facts ClassicRunDex uses to answer Player Jobs, such as Cookies, Pets, Treasures, Levels, Costs, Episodes, and Combinations. Player Data is not advice by itself.
_Avoid_: content dump, scraped stuff

**Player Guide**:
Actionable, dated interpretation of Player Data for a specific Player Job. A Player Guide recommends what to use, unlock, upgrade, compare, or avoid without presenting unverified Kakao or community leads as Classic facts.
_Avoid_: wiki page, info page

**Launch Checklist**:
A supporting utility that points Returning Thai Players to current official code, event, invite, reward, or support actions with last-reviewed and expiry context. A Launch Checklist item does not collect account information or drive Player Guide recommendations.
_Avoid_: coupon page, reward farm, official service

**Trust Policy Surface**:
A player-visible statement of ClassicRunDex's trust boundaries, such as non-affiliation, source review, account/coupon refusal, monetization refusal, or safe share wording.
_Avoid_: legal footer, disclaimer blob

**Week-One Launch Loop**:
The first manual feedback cycle after launch that watches whether Returning Thai Players reuse the guide, report corrections safely, find stale claims, and leave the maintainer workload manageable. The loop uses repo-owned notes and GitHub Issues, not analytics SDKs.
_Avoid_: analytics, growth loop, telemetry

**Launch Signal**:
A manually reviewed observation used by the Week-One Launch Loop to decide whether to keep, fix, or narrow ClassicRunDex's launch scope.
_Avoid_: metric, KPI, event

**Player Job**:
A concrete decision or task a player comes to ClassicRunDex to complete, answered by Player Data plus a Player Guide.
_Avoid_: feature idea, content category

**Returning Thai Player**:
A Thai-language player with prior Cookie Run familiarity who needs fast, practical answers for Cookie Run Classic.
_Avoid_: Thai market, casual user

**Cookie**:
A playable runner character in Cookie Run Classic or Cookie Run Kakao. ClassicRunDex describes a Cookie by names, source status, Skill, Levels, Costs, related Pet/Treasure, and relevant Combinations.
_Avoid_: character, unit, hero

**Pet**:
A companion entity that accompanies a Cookie and contributes effects, bonuses, or progression value.
_Avoid_: companion, sidekick

**Treasure**:
An equipable or unlockable item that changes run performance, progression, scoring, or resource value.
_Avoid_: item, artifact, gear

**Combination**:
A meaningful Cookie, Pet, Treasure, Episode, or condition relationship that changes expected performance, scoring, bonus value, or guide relevance. This includes in-game Combi bonuses and guide-recommended loadouts.
_Avoid_: team, build, combo

**Skill**:
An effect or ability tied to a Cookie, Pet, or Treasure that can affect scoring, survival, collection, generation, or progression.
_Avoid_: power, perk

**Level**:
An upgrade state for a Cookie, Pet, Treasure, or account system within a specific game and version.
_Avoid_: stage, rank

**Cost**:
A required in-game resource amount to unlock, upgrade, evolve, hatch, draw, or otherwise obtain a game entity.
_Avoid_: price, value

**Episode**:
A named gameplay area or run context where runs, rewards, scoring, availability, or recommendations may differ.
_Avoid_: world, map, stage

**Source Record**:
The provenance attached to a Player Data fact or Player Guide claim: where it came from, who owns it, when it was observed, and whether it is official, player-verified, historical, or only a lead.
_Avoid_: citation, scrape note

**Contribution Report**:
A GitHub-native request from a player or contributor that proposes a correction, missing Player Data, Translation, Source Record, Classic-vs-Kakao Difference, or Player Guide impact. A Contribution Report starts review; it is not proof by itself.
_Avoid_: submission, ticket dump, proof

**Contribution Claim**:
A specific assertion inside a Contribution Report or Contribution Packet that may become Player Data, a Translation, a Source Record, or Player Guide context after review.
_Avoid_: fact until verified, user truth

**Contribution Packet**:
A reviewable bundle of Source Records, proposed Player Data facts, Translations, and Player Guide impact prepared for publication. A Contribution Packet cannot make a recommendation-driving claim without Data Reviewer or Maintainer approval.
_Avoid_: import batch, patch dump

**Data Changelog**:
A generated audit record for a published Contribution Packet that names changed Contribution Claims, Source Records, source status, contributors, reviewers, Player Guide impact, and superseded or disputed context. A Data Changelog is derived from reviewed packet data, not hand-written freeform notes.
_Avoid_: release notes, edit summary

**Review State**:
The lifecycle state of a Contribution Claim, such as reported, needs-info, candidate, verified Classic, official Classic, historical Kakao, Translation-only, community lead, rejected, or superseded.
_Avoid_: source status, issue label

**Translation**:
A ClassicRunDex wording that maps Thai, English, Korean, or historical names/descriptions into player-facing Thai or English without copying source prose. A Translation is not itself verification.
_Avoid_: localization, machine translation dump

**Classic-vs-Kakao Difference**:
A verified or suspected difference between CookieRun Classic and Cookie Run Kakao in names, availability, values, mechanics, or guide relevance.
_Avoid_: change, mismatch
